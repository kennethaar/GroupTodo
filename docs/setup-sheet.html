Two minutes, on a computer

Setting up GroupTodo

A shared to-do list that keeps everything as ordinary text files in your own OneDrive. Nothing to install, no account, no password. Two minutes and you and your colleagues are working on the same list.

Why this one can be shared

Most task apps keep your tasks on their servers. That is the reason sharing one is such a nuisance.

Everybody needs an account on the same thing, somebody has to pay for the seats, and getting a colleague added means a request to whoever administers it. So people give up and paste lists into chat instead.

GroupTodo has no server, so there is nothing to be a member of. Your tasks are plain text files sitting in a folder. Share the folder the way you already share folders and you are done — the sharing is your company's, not ours. Nobody is invited to anything, nobody pays for a seat, and when somebody leaves you remove them from the folder.

It also means the list outlives the tool. The files open in Notepad.

Do this now

The whole setup

  1. Open index.html Double-click it. Use Edge or Chrome. Nothing installs.
  2. Choose Start a new list and type your first task The box is already waiting for you. Press Enter.
  3. Click ⇆ Vault & sync, then Choose folder Pick the shared folder in OneDrive. Say yes when Edge asks to let the page edit it. Your tasks are now files in there, saved as you type.
  4. Put your first name in Your name, same panel This is what makes it a team list rather than a pile: your own day pages, your name on what you take on, and you show up for everybody else.

That is it. Send your colleagues this sheet, the index.html file and the name of the shared folder, and they do the same four steps.

Learn it by using it

Four things, and nothing else to read

Nothing is hidden, but nothing shows up before it is about something. Options appear as you start needing them.

Today is yours
Your day page is your own, so nobody is typing over you. What you put on it is still visible to everyone.
A task is yours by default
Write it, it is yours. No assigning, no ceremony.
Hand it over and it tracks itself
Give a task to a colleague and it becomes theirs — and shows up in your Waiting for. One task, two points of view, never two copies.
Name somebody outside
Somebody who is not on the folder cannot tick anything off, so it becomes a plain waiting-for instead of pretending to be their task.
People
Appears once there is more than you. Shows who is carrying what, which is the half that Waiting for never tells you.
Tick the states you want to see
To do, Doing and Waiting for are checkboxes, so you can read them together or one at a time. A state you have never used is never mentioned.
Everything in the folder is shared. That is the only rule.

There are no per-task permissions, because the folder is the permission. If something should not be seen, open the page and use make private — it asks which other folder to move it to, because moving it is the only thing that actually makes it private.

Advanced

When you want more

Put it on your phone needs a web link, about ten minutes

A phone can run GroupTodo, but not from a file. Phones refuse to give a page opened as a file anywhere to save, and they cannot open folders at all. So the phone needs a web address, and it keeps its own copy that you carry back and forth as a single file.

Do not tap index.html in the OneDrive app

It opens, looks fine, saves nothing, and loses what you typed when you close it. GroupTodo will warn you. Use the link.

  1. Somebody puts the four files on a web address Once, for everyone. Your intranet or a SharePoint-hosted site is tidiest at work. A document library will not work — that is file storage, not a web host.
  2. Open that address on the phone, then Add to phone You get an icon, and after the first visit it opens with no signal.
  3. On the computer: Link vault file, saved beside the folder Call it work-vault.md. Next to the folder, not inside it. The computer then keeps it up to date on its own.
  4. On the phone: Open vault file to collect, Send vault file to post back Two taps, one each way. Nothing is ever overwritten — both sides' work survives.
Everything in sync, no file passing one always-on machine

If somebody has a machine that is always on, it can serve the list to everybody — computers and phones, live both ways, no vault file to carry. It needs a password and ten minutes of setup by whoever owns the machine. Ask them to read README.md.

Separate parts of your life work, home, volunteering

Each one is its own folder, called a space. Two spaces can never share a folder and one can never sit inside another, so the folder you share is exactly what you meant to share. Colleagues who get Work cannot see Home, because it is not in there.

If it is not behaving the three things that actually go wrong
A warning that nothing can be saved
You opened it inside something that will not let it store anything — usually a preview in a document library. Download the file and open it from your computer.
“browser only — no files” at the top
No folder chosen yet, so nothing is being written. Vault & sync → Choose folder. On a phone this is normal and expected.
You cannot find the files
Only a computer writes them, and only after you pick a folder. Look inside it: journals\ is one file per person per day, pages\ one file per project and list.
Your tasks stay in your folder. The app cannot send them anywhere — it is blocked from reaching the internet at all, which is also why there is nothing to log in to. Stuck on a step? Ask whoever sent you this.
