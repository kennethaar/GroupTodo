One-page setup

Setting up GroupTodo

A shared to-do list that keeps everything as ordinary text files in your own OneDrive. Nothing to install, no account, no password. This sheet gets you running on a computer and a phone in about ten minutes.

The idea, in one picture

Your computer keeps the files. Your phone keeps a copy.

This is the only part worth understanding. A computer can write real files into a OneDrive folder. A phone cannot — phones do not let web pages touch folders. So the phone holds its own copy of the list, and one small file carries changes between the two.

Do not open the app from OneDrive on your phone

If you tap the index.html file in the OneDrive app, the page opens but the phone gives it nowhere to save. It shows a red warning, and everything you type is lost when you close the tab. On a phone, always open the web link below instead.

Done once, by one person

Put the app on a web link

Everyone else just opens a link, so somebody has to make one. The app is four files and needs no server, no database and no software — any place that can show a web page will do.

  1. Pick somewhere to put it

    Your company intranet or a SharePoint site is the right answer at work: already private, already behind your login, and nothing appears on the public internet. Ask IT for a folder that serves web pages. A free public host such as GitHub Pages also works, and is fine for an ordinary to-do list, but see the note below first.

  2. Upload all four files together

    index.html, sw.js, manifest.webmanifest, icon.svg. The first one is the app; the other three are what let a phone keep it on the home screen and open it without signal.

  3. Send the link round

    Along with the name of the shared OneDrive folder the team will use.
A public link does not make your tasks public

The link hands out the empty app and nothing else. Your tasks are written to your own folder or kept inside your own browser, and the app is blocked from sending them anywhere. What the host does see is the ordinary web-server record — your IP address, the time, and that you opened the page. Nothing about what is in your list. If even that is too much, use the company intranet or any host behind a login, and note that a computer needs no link at all: opening the downloaded file works fully there. The link is only for phones.

Everyone, about five minutes each

Your turn

On your computer

Use Edge or Chrome. This is where the real files live.
  1. Open the link.
  2. Choose Start a new list. The task box is already waiting. Type something and press Enter.
  3. Click ⇆ Vault & sync at the top.
  4. Click Choose folder and pick your OneDrive folder. Say yes when Edge asks to let the page edit it. From now on every day and every project is its own file in there, and OneDrive backs them up.
  5. Click Link vault file and save it as work-vault.md. Put it next to the folder, not inside it. This is the file your phone will read. After this the computer looks after it on its own.

On your phone

Any phone, any browser. No app store, no download.
  1. Open the same link in your phone’s browser. The link — not the file in OneDrive.
  2. Open the browser menu and tap Add to phone or Add to Home Screen. You get an icon like any other app. From then on it opens even with no signal.
  3. Tap the icon, then ⇆ Vault & sync.
  4. Tap Open vault file and pick work-vault.md from OneDrive. Your list appears. You now have it in your pocket.
Day to day

Moving work between the two

Two taps on the phone, nothing on the computer. Think of it as posting a letter: one to send, one to collect.

You type on the computer Saved into the OneDrive folder straight away. A minute after you stop, work-vault.md is refreshed too.
Phone: Vault & sync → Open vault file Collects everything from the computer. A short message says what arrived.
You type on the phone Saved on the phone.
Phone: Vault & sync → Send vault file, then share to OneDrive Posts your changes back.
You sit back down and click into the tab The phone’s changes appear by themselves, and anything new becomes its own file in the folder.

Nothing gets overwritten. If you and a colleague both added tasks to the same day, both sets turn up. Ticking something off on the phone keeps it ticked off on the computer. Collecting the same file twice changes nothing, so an extra tap is never a risk.

Working together

Sharing with colleagues

Share the OneDrive folder itself, in OneDrive, with the people who should see it. They point their copy of GroupTodo at that folder and you are working on the same list.

Keep separate parts of life in separate folders — one for work, one for home. GroupTodo calls these spaces and will not let two of them share a folder, so the folder you share is exactly what you meant to share and nothing more. It works best when you each look after different projects; two people rewriting the same page in the same minute is the one thing that gets untidy.

Who can see what is decided by OneDrive, not by GroupTodo

There are no accounts and no passwords here. Anyone who can open the folder can read and change everything in it. That is the same as a shared folder of Word documents — treat it the same way.

If something looks wrong

The four things that actually go wrong

A red warning about nothing being stored
You opened the file instead of the link. Close it, open the web link, and on a phone add it to your home screen.
It says “browser only — no files” next to the tick at the top
No folder has been chosen yet, so nothing is being written. Go to Vault & sync → Choose folder. On a phone this is normal and expected — phones never write files.
You cannot find your markdown files
Only a computer writes them, and only after you have chosen a folder. Look inside the folder you picked: journals\ holds one file per day, pages\ one file per project, list and person.
OneDrive saved work-vault (1).md
Some phones add a number instead of replacing the file. Harmless — open the newest one on the computer, then delete the spares when you next tidy up.
GroupTodo keeps your tasks as plain markdown files you own. It cannot send them anywhere: the page is blocked from reaching the internet at all, which is also why there is nothing to log in to. Stuck on a step? Ask whoever sent you the link.
